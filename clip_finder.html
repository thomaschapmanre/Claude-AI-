Chat Spike Clip Finder

Drop in a VOD's chat log and get the moments where chat blew up, each with a clip start time 20 seconds early so you catch the setup. Everything runs in this page; your file is not uploaded anywhere.

1. Chat file

Drop chat JSON here or click to choose a file

Get the file from TwitchDownloader: Chat Download, format JSON.

2. VOD link (optional)

Adds a button to each moment that opens the VOD at the clip start. A link on its own can't load chat, because Twitch doesn't offer VOD chat to other sites.

3. Tuning

One per line. A bonus of 1 makes that message count double. End a word with * to match anything that starts with it (pog* catches PogChamp and POGGERS). Upper and lower case don't matter.
