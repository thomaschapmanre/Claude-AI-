# Chapman Notary Services website

Static site in `docs/` (no build step). Publishing steps: `PUBLISHING.md`.

## Before writing any HTML/CSS
Always invoke the `frontend-design` and `taste` skills (in `.claude/skills/`) first, write a short design plan, then build. Screenshot the page at 390px wide and review it before calling it done.

## NYS compliance (never break these)
- Notary fees: $2 per signature; electronic notarization max $25. Travel fees listed separately, agreed in advance, never called a notarial fee.
- Show the not-an-attorney disclaimer (Executive Law §135-c wording) on every page with services or fees.
- Never use the phrase "notario público" or similar.
- Any page in a language other than English must include the §135-c disclaimer and the fee schedule in that language.
